SmarterChores will be a Python-Flask based Progressive Web Application that allows users to:
- Register and log in securely
- Create and delete chores
- Mark them as complete or incomplete
- Check their daily chores
- Set time to complete chores by

**Key Features**:
The Key features of SmarterChores are:
Functional: 
- User Authentication, dashboard containing a list of all chores, daily chore table
Performance:
- Fast load times with minimal disruptions
Security:
- Password hashing, input validation and sanitisation, session management and protection against SQL injection
Privacy:
- Compliance with the Australian Privacy 

**User Experience:**
The interface will be designed with desktop and mobile device in mind. It will be simple, clean and intuitive to use, accessible from all devices from a browser of choice. 

**Technologies**
SmarterChores will be based on the following 3rd-part technologies:
- Backend: Python, Flask
- Frontend: HTML5, CSS3, Bootstrap
- Database: SQLite
- Authentication: Flask-Login
